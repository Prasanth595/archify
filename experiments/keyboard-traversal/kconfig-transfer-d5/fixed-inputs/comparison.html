Why does absence from the config not mean uncalculated?

The generated config omits the unmet target.7 Its value n comes from the observed JSON and the native formatter, not an explicit config line.15 All three relevant symbols have visibility n and no user value in this run. Visibility n means the symbol is not visible as a menu prompt; it does not mean its value was not calculated.81
