What does singleflight suppress?

Long image

A

Answer

Within one Group, singleflight shares one in-flight function call among callers using the same key. It does not keep a completed result as a cache, and Forget lets a new call start without stopping the old one.123

  1. Overlapping calls for a key share the first call's value and error.1
  2. After completion, a later call normally runs its function again.2
  3. After Forget, an old and a new call for the same key can overlap.3

What happens when callers overlap?

Caller B joins the existing call for user:42; B's function is not run. The sequence then shows Forget before that call finishes.13

Diagram structure
  • Caller A a
  • Caller B b
  • Caller C c
  • Controller control
  • Group group
  • Function work
  • a → group · Do user:42
  • group → work · Start A's function
  • b → group · Do user:42; wait
  • control → group · Forget user:42
  • c → group · New Do user:42
  • group → work · Start new function
  • work → group · Old call completes
  • group → a · Old value and error
  • group → b · Old value and error

The new call can complete independently. Completion of the old call does not remove the new call's entry: cleanup deletes only if the entry still points to the old call.2

How is this different from a cache?

After Forget?Later calls may start new work; existing work continuesRetention and invalidation depend on the cache

Singleflight does not supply storage, expiry or invalidation policy. A cache and singleflight can be used together: check the cache, then coalesce concurrent misses.12
