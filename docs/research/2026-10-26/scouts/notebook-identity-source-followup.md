# nbdime ID 跟进：数据层保留与视图“未变”判断是两件事

固定上游 [jupyter/nbdime@744c97897e2c33a1b3f04f5834ee6e70478219a2](https://github.com/jupyter/nbdime/tree/744c97897e2c33a1b3f04f5834ee6e70478219a2)，只读源码；修改 `/tmp/archify-round15-notebook-diff-reading.md` 的保守表述：**可以确认前端 `unchanged` 判断没有检查 `cellId`，且 unchanged 样式隐藏 cell ID；源码也支持默认未过滤情况下保留 ID 的 atomic replace。** 不需要依靠实际运行才能确认这些有限合同。但对上游 test1 截图当时服务的实际外部配置和该次完整响应，仍没有运行回执，不能把源码推导说成实测 JSON。

[Playwright 配置](https://github.com/jupyter/nbdime/blob/744c97897e2c33a1b3f04f5834ee6e70478219a2/ui-tests/playwright.config.js) 启动 `npm start`，可能在非 CI 复用现有服务；[package.json](https://github.com/jupyter/nbdime/blob/744c97897e2c33a1b3f04f5834ee6e70478219a2/ui-tests/package.json) 运行不含过滤选项的 `nbmerge-web -p 41000 ...`；[测试](https://github.com/jupyter/nbdime/blob/744c97897e2c33a1b3f04f5834ee6e70478219a2/ui-tests/tests/nbdime-diff-test1.spec.ts) 打开 `/diff` 并填 base/remote。`nbmerge-web` 的 [main](https://github.com/jupyter/nbdime/blob/744c97897e2c33a1b3f04f5834ee6e70478219a2/nbdime/webapp/nbmergeweb.py#L48-L66) 解析配置及过滤参数；[ConfigBackedParser](https://github.com/jupyter/nbdime/blob/744c97897e2c33a1b3f04f5834ee6e70478219a2/nbdime/args.py#L23-L35) 还可加载外部 Ignore 配置。无自定义忽略时，[targets](https://github.com/jupyter/nbdime/blob/744c97897e2c33a1b3f04f5834ee6e70478219a2/nbdime/diffing/notebooks.py#L590-L608) 的 `identifier=True`，并不默认移除 ID；若配置或显式过滤发生变化，结论需重核。服务的 [API diff](https://github.com/jupyter/nbdime/blob/744c97897e2c33a1b3f04f5834ee6e70478219a2/nbdime/webapp/nbdimeserver.py#L208-L223) 将 base/remote 传给 `diff_notebooks`，返回 base 和 diff；[页面选项](https://github.com/jupyter/nbdime/blob/744c97897e2c33a1b3f04f5834ee6e70478219a2/nbdime/webapp/nbdimeserver.py#L43-L54) 默认 hideUnchanged=True。
2. 对这对固定 fixture，仅首 cell source/type/outputs 相同但 ID 不同：依 [predicates](https://github.com/jupyter/nbdime/blob/744c97897e2c33a1b3f04f5834ee6e70478219a2/nbdime/diffing/notebooks.py#L294-L384) 与 [多级优先规则](https://github.com/jupyter/nbdime/blob/744c97897e2c33a1b3f04f5834ee6e70478219a2/nbdime/diffing/notebooks.py#L521-L555)，ID 谓词不能匹配，但 strict source/output 可回退匹配；[snakes](https://github.com/jupyter/nbdime/blob/744c97897e2c33a1b3f04f5834ee6e70478219a2/nbdime/diffing/snakes.py#L33-L93) 对已对齐 cell 递归 diff。`/cells/*/id` 被配置为 atomic；[generic diff_dicts](https://github.com/jupyter/nbdime/blob/744c97897e2c33a1b3f04f5834ee6e70478219a2/nbdime/diffing/generic.py#L239-L285) 对两个都有且不同的 atomic 字段产生 replace。因此**在未应用忽略配置且按该源码执行的条件下**，这一固定 pair 的首 cell 应有 ID replace patch；这是从源码和输入的推导，非实际捕获或完整测试 oracle。
3. [CellDiffModel](https://github.com/jupyter/nbdime/blob/744c97897e2c33a1b3f04f5834ee6e70478219a2/packages/nbdime/src/diff/model/cell.ts#L89-L105) 的 `unchanged` 检查 source、metadata、outputs、executionCount，**不检查 cellId**；[patched model](https://github.com/jupyter/nbdime/blob/744c97897e2c33a1b3f04f5834ee6e70478219a2/packages/nbdime/src/diff/model/cell.ts#L155-L211) 则从 diff 读取 ID 并构建 idModel。故只有 ID 变化时该 cell 仍被标记 unchanged；这不是说底层 diff 必然没有 ID。widget 将模型标为 unchanged，并创建两侧 ID header；[CSS](https://github.com/jupyter/nbdime/blob/744c97897e2c33a1b3f04f5834ee6e70478219a2/packages/nbdime/src/styles/diff.css#L25-L33) 对 unchanged cell 的 ID header 设 `display:none`。因此即使切换显示被隐藏的 unchanged cell，该规则下 ID header 仍隐藏。前提是 cell 按上述方式对齐，且浏览器使用该 CSS；无本轮浏览器运行。
4. 上游 [expected screenshot](https://github.com/jupyter/nbdime/blob/744c97897e2c33a1b3f04f5834ee6e70478219a2/ui-tests/tests/nbdime-diff-test1.spec.ts-snapshots/diff-test1-take-a-snapshot-at-opening-1-linux.png) 的 `1 unchanged cell(s) hidden` 与源码的视觉规则一致，但不是网络响应；这次搜索未找到此 pair 的独立 expected machine diff 或专门断言 ID-only 视觉行为的测试。不要用截图推断 CI 当时是否应用了用户配置，也不能把它外推到所有 ID、移动/拆分或未来版本。
