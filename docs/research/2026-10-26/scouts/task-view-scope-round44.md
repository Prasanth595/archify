## 本批解决的问题

第 18 批用上游原生 demo 检查了 scoped graph，但输入不同于 Archify 历史实验，不能宣布旧实验已被覆盖。本批复用 task-flow-tests@843c877 的同一 mapping、flows 与 project.mjs，执行固定新版 task-view@a3fa217 的 testsOf/scopedNodeIds 源码片段。

三条路径共用 guard/report。原 mapping 已有 regression → guard 的代码级声明边，而 sidecar 仅为 missing 路径声明测试，另两条为未声明（其中 omitted-link 是合成对照）。全局节点关联与较窄的路径声明可以同时成立。

| 局部表示 | 三条路径的关联数量 |
| --- | --- |
| 原实验路径声明 | 1／0／0 |
| 共用节点的全局测试边 | 1／1／1 |
| 只有旧 flow.tests 字段 | 0／0／0 |
| 每路径独立节点 ID 或独立文档 | 1／0／0 |

这不是测试执行、分支覆盖或产品缺陷证据。task-view 的代码级关联没有承诺覆盖所有路径。替代编码改变身份或文档范围，未做 schema、Git、布局及浏览器验收；不能当成已交付的转换器。

源码同时确认旧 flow.tests 仍有节点引用校验，页面数据也保留它；前端节点测试查询却使用 tests 边。不能因为旧字段能被读取，就推断当前界面继续展示它。
